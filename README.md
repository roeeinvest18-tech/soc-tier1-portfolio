## Evidence and Scope

These projects demonstrate training experience and do not represent production SOC employment. The packet case studies publish analysis notes rather than the original PCAPs or screenshots. The SPL examples are search fragments and proposals, not validated production detection rules.

Start with Meridian for multi-source correlation and handover, then review the smaller cases for focused methodology. See [CV project summary](CV_PROJECT_SUMMARY.md) for concise project descriptions.
